# Security Policy & Vulnerability Reporting

---

## 1. Supported Versions

| Version | Supported |
| :--- | :--- |
| `v1.2.x` | :white_check_mark: Active Support |
| `< v1.2` | :x: End of Life |

---

## 2. Reporting a Vulnerability

If you discover a security vulnerability within MoodFeed, please report it privately:
- **Email:** `security@moodfeed.app`
- **PGP Key:** Available upon request.
- **Response SLA:** Initial acknowledgment within 24 hours; patch and mitigation within 7 calendar days.
- **Do not open public GitHub issues for security vulnerabilities.**
